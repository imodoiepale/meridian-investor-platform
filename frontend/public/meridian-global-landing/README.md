# Meridian Global Landing Page

Static responsive landing page package based on the approved Meridian full-page design.

## Run locally

Open `index.html` directly, or serve the folder:

```bash
python -m http.server 4173
```

Then visit `http://localhost:4173`.

## Files

- `index.html` - semantic page structure
- `styles.css` - complete responsive styling
- `script.js` - sticky navigation, mobile menu, and form interactions
- `assets/images/hero-global-investors.png` - hero image
- `assets/images/market-selection-nairobi.png` - market selection image
